# Tapete de Danza

Juego de ritmo en Unity que se controla con un tapete de baile físico. Las cuatro zonas del tapete corresponden a los cuatro carriles del juego, y el jugador debe pisar cada zona cuando la nota llega al receptor.

## Controlador físico

El tapete usa una placa de teclado USB conectada a cuatro zonas de contacto. Cada zona envía una tecla al computador:

| Zona | Tecla |
|------|-------|
| Izquierda | K |
| Abajo | V |
| Arriba | Flecha arriba |
| Derecha | X |

## Cómo jugar

1. Conectar el tapete por USB.
2. Abrir `Tapete de Danza.exe` desde la carpeta del build.
3. Cargar una canción desde el menú y presionar Iniciar juego.
